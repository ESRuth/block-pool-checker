# Code of conduct

This is a small, friendly project. Be kind and be useful.

## What we expect
- Be respectful of people and their work, including when you disagree.
- Assume good faith, give specific and constructive feedback, and accept it the same way.
- Keep to the topic: the code, the docs and the app.
- Never post other people's private information. That includes real pool photos, names and phone numbers (see `CONTRIBUTING.md`).

## What is not acceptable
Harassment, insults, discrimination, personal attacks, or publishing someone's private information.

## Reporting and enforcement
Report a problem by opening a [private security advisory](https://github.com/ESRuth/block-pool-checker/security/advisories/new) on the repository (it reaches only the maintainer) or by contacting the maintainer, [@ESRuth](https://github.com/ESRuth), on GitHub. The maintainer may edit or remove comments, issues and pull requests, and may block contributors who break these rules.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
